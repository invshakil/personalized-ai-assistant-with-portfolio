# Yarn 1 and Node 22 (#19)

**The package manager becomes Yarn 1, as in CT Admin, and Node 22 is the version for `.nvmrc`, `engines` and CI** (Shakil, 25 Nov 2026).

- **Why:** `packageManager` already said Yarn 1 while the lockfile, the hooks, CI and the deploy used npm. One package manager across both projects means one set of commands. The droplet's setup notes install Node 22, and CI already uses it.
- **Instead of:** staying on npm and removing the `packageManager` field.
- The switch is the tooling PR: it adds `yarn.lock` and removes `package-lock.json` in the same PR. The droplet needs Yarn, through corepack, before the first deploy after that merge. Until then the repo is on npm.
