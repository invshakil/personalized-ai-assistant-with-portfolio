# Next.js App Router as the framework

**The site is one Next.js application on the App Router, serving both the public portfolio and the private admin** (Shakil, 8 Jun 2026).

- **Why:** server-side rendering helps the portfolio's SEO, and server components reduce the JavaScript sent to the browser.

The project is on Next.js 16 with TypeScript and a `src/` directory. The portfolio is at `/`, the admin at `/admin`.
