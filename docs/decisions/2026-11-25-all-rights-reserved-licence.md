# All rights reserved licence (#19)

**The repo gets a `LICENSE` file that reserves all rights: the source can be read, and nothing else is permitted without written permission** (Shakil, 25 Nov 2026).

- **Why:** the README already said "all rights reserved", but a public repo with no licence file leaves visitors guessing.
- **Instead of:** an open-source licence. This is a personal site and admin, not a library.
