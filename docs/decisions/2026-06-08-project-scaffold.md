# Next.js project scaffolded

**The Next.js project was scaffolded with the App Router, Prisma, NextAuth credentials and the admin layout** (Shakil, 8 Jun 2026).

What the scaffold contained:

- App Router project structure.
- The Prisma schema.
- NextAuth with the credentials provider.
- Middleware protecting the admin routes.
- The admin layout and sidebar.
- Portfolio component stubs.
- The login page.
- `CLAUDE.md` and `PROJECT_PLANNING.md`.

Since then: the request interceptor is `src/proxy.ts` (the Next.js 16 name), not `middleware.ts`. `PROJECT_PLANNING.md` was replaced by `docs/ARCHITECTURE.md`, `docs/STATUS.md` and this folder.

The first commit is `8b3f7f2`.
